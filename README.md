🚀 Automating EC2 + S3 Setup with IAM Using AWS CLI & Bash

I’m excited to share another hands-on step in my DevOps learning journey — building a real-world AWS automation workflow using AWS CLI and Bash scripting.

🎯 Project Objective:
Automate the provisioning and configuration of an Amazon EC2 instance that can securely interact with an Amazon S3 bucket.

🔧 Key Areas Covered:

☁️ Provisioning an EC2 instance using AWS CLI

🪣 Configuring S3 access for the EC2 instance

🔐 Using IAM roles and permissions following the principle of least privilege

⏹️ Implementing auto-stop and auto-start based on business requirements

🖥️ Automating infrastructure using Bash scripting

🔁 Applying repeatable Infrastructure as Code (IaC) practices

⚙️ Building a workflow that reduces manual AWS configuration


This practical project helped me understand how AWS services, IAM, EC2, S3, and automation scripts work together in a real DevOps environment.
